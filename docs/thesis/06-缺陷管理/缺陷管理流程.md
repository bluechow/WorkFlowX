# 缺陷管理流程

## 1. 缺陷生命周期

```
新建(New) → 确认(Confirmed) → 修复(Fixed) → 验证(Verified) → 关闭(Closed)
                ↓                    ↓
            拒绝(Rejected)       重新打开(Reopened) → 修复...
```

## 2. 缺陷等级定义

| 等级 | 名称 | 定义 | 示例 |
|---|---|---|---|
| P0 | 致命 | 主流程阻塞/数据丢失/安全漏洞 | 登录无法使用；越权访问他人数据 |
| P1 | 严重 | 核心功能错误，无绕过办法 | 状态流转不生效；审计日志丢失 |
| P2 | 一般 | 非主流程错误，有绕过办法 | 筛选条件不生效但可通过搜索替代 |
| P3 | 轻微 | 文案/样式/体验问题 | 按钮文字错误；颜色不规范 |
| P4 | 建议 | 改进建议 | 建议增加批量操作功能 |

## 3. 缺陷报告模板

```markdown
## BUG-<序号> <一句话标题>
- 级别：P0/P1/P2/P3/P4
- 模块：<所属功能模块>
- 环境：localhost:8081 / Chrome / <测试账号>
- 复现概率：必现 / 偶现（概率）
- 复现步骤：
  1. ...
  2. ...
  3. ...
- 预期结果：...
- 实际结果：...
- 截图/日志：<路径或粘贴>
```
