# WorkFlowX 测试报告

> 被测系统：WorkFlowX v2.1.0（企业项目协作与工作项管理平台）
> 测试周期：2026-09 ~ 2026-10
> 报告日期：2026-10-13

## 1. 测试概述

### 1.1 测试目的

验证 WorkFlowX 系统满足需求分析中定义的 22 项业务能力，评估系统质量是否达到交付标准。

### 1.2 测试范围

| 测试类型 | 覆盖范围 |
|---|---|
| 功能测试 | 认证/权限/组织/项目/工作项/看板/评论/附件/通知/测试管理/质量分析/审计 |
| 接口测试 | 25 个控制器 / 95+ 个 REST 端点 |
| UI 自动化 | 登录/项目空间/看板/测试计划/搜索/通知 |
| 性能测试 | 核心接口响应时间与并发能力 |

### 1.3 测试环境

- 被测系统：http://localhost:8081（Docker Compose 五容器）
- 数据库：MySQL 8.0（19 个 Flyway 迁移，59 项权限种子）
- 测试数据：50 用户 / 7 项目 / 50 工作项 / 36 测试用例 / 2 测试计划

### 3.2 缺陷明细

| 编号 | 标题 | 等级 | 模块 | 根因 | 修复方式 |
|---|---|---|---|---|---|
| HIST-001 | 列表页数据空白 | P1 | 前端 API 层 | Axios 拦截器已解包但页面二次解包 | 统一走 API 封装函数 |
| HIST-002 | 取消分派不生效 | P1 | 后端工作项 | MyBatis-Plus 默认跳过 null 字段 | 显式 LambdaUpdateWrapper set null |
| HIST-003 | 状态标签显示英文 | P3 | 前端工作项 | 下拉只渲染合法目标不含当前状态 | 补禁用当前状态选项 |
| HIST-004 | 测试用例 403 误报 | P2 | 测试用例 | 用例缺少项目成员步骤 | 补 addProjectMember 步骤 |
| HIST-005 | 权限对话框布局混乱 | P3 | 前端角色管理 | 按钮字号/颜色/分组不一致 | RowActions 组件统一 |
