## 与被测系统的关系

被测系统 WorkFlowX 是一个开源的企业项目协作与工作项管理平台，
源代码位于本仓库的 `backend/`、`frontend/` 目录。

**本目录（docs/thesis/）是站在测试工程师视角的独立交付物**，
不包含任何开发代码——测试用例基于需求分析设计（黑盒原则），
不依赖对源代码的阅读。

被测系统自带的测试套件（backend 355 个 + frontend 169 个）属于
开发方的单元/集成测试，与本目录的测试工作是互补关系：
- 开发方测试：验证代码实现正确性（白盒/灰盒）
- 本测试工作：验证系统满足用户需求（黑盒）
