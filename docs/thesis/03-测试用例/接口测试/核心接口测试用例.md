# 接口测试用例 — 核心接口（P0）

> 用例设计方法：**等价类划分 + 边界值分析**
> 工具：pytest + httpx（黑盒测试，不查看源代码）
> 认证方式：Bearer Token（登录接口获取）

## 1. 认证接口

### TC-API-AUTH-001~005：登录接口

| 用例编号 | 输入 | 预期输出 | 设计方法 |
|---|---|---|---|
| TC-API-AUTH-001 | 正确用户名+密码 | 200 + accessToken + 用户信息 | 有效等价类 |
| TC-API-AUTH-002 | 错误密码 | 401 + "用户名或密码错误" | 无效等价类 |
| TC-API-AUTH-003 | 不存在的用户名 | 401 + 同上（不泄露存在性） | 无效等价类 |
| TC-API-AUTH-004 | 密码连续错 5 次 | 第 6 次返回 429 + "尝试次数过多" | 边界值 |
| TC-API-AUTH-005 | 空用户名/空密码 | 422 + 参数校验错误 | 边界值 |

### TC-API-AUTH-006~010：会话管理

| 用例编号 | 场景 | 预期 |
|---|---|---|
| TC-API-AUTH-006 | 登录后调用 /auth/me | 200 + 当前用户信息 |
| TC-API-AUTH-007 | 登出后用旧 Token 调用 /auth/me | 401 |
| TC-API-AUTH-008 | 二次登录后旧 Token 调用 /auth/me | 401（单会话） |
| TC-API-AUTH-009 | 修改密码后旧 Token | 401 |
| TC-API-AUTH-010 | Token 过期（等待 2h） | 401 |

## 2. 工作项接口

### TC-API-ITM-001~010：创建工作项

| 用例编号 | 输入要点 | 预期 | 设计方法 |
|---|---|---|---|
| TC-API-ITM-001 | 标题=1 字符 | 201 + 编号=1 | 最小边界值 |
| TC-API-ITM-002 | 标题=200 字符 | 201 | 最大边界值 |
| TC-API-ITM-003 | 标题=201 字符 | 422 + "title 最长 200" | 超出边界 |
| TC-API-ITM-004 | 标题为空 | 422 | 无效等价类 |
| TC-API-ITM-005 | 类型=BUG + 严重度=S1 | 201 | 有效组合 |
| TC-API-ITM-006 | 类型=TASK + 严重度=S1 | 400 + "severity 仅适用于 BUG" | 无效组合 |
| TC-API-ITM-007 | 经办人=项目成员 | 201 + 分派通知 | 有效等价类 |
| TC-API-ITM-008 | 经办人=非项目成员 | 400 | 无效等价类 |
| TC-API-ITM-009 | 标题含特殊字符 `<script>` | 201 + 原样存储（转义由前端处理） | 安全相关 |
| TC-API-ITM-010 | 并发创建 10 个 | 编号 1~10 不重复 | 并发正确性 |

### TC-API-ITM-011~015：查询与筛选

| 用例编号 | 场景 | 预期 |
|---|---|---|
| TC-API-ITM-011 | 关键词搜索命中 | 返回包含关键词的工作项 |
| TC-API-ITM-012 | 按标签筛选 | 仅返回绑定该标签的工作项 |
| TC-API-ITM-013 | 按截止日期范围筛选 | 仅返回范围内的 |
| TC-API-ITM-014 | 分页 page=1&size=10 | 返回第一页最多 10 条 |
| TC-API-ITM-015 | 传入不存在的项目 ID | 404 |

## 3. 测试管理接口

### TC-API-TST-001~008：测试计划执行

| 用例编号 | 场景 | 预期 |
|---|---|---|
| TC-API-TST-001 | 创建计划 | 201 + 状态 NOT_STARTED |
| TC-API-TST-002 | 添加用例到计划 | 200 + 条目创建 |
| TC-API-TST-003 | 重复添加同一用例 | 跳过（幂等） |
| TC-API-TST-004 | 执行用例为 PASS | 200 + 结果更新 |
| TC-API-TST-005 | 执行为 FAIL 时关联 Bug | 200 + 关联成功 |
| TC-API-TST-006 | NOT_STARTED 状态下执行 | 400 + 错误提示 |
| TC-API-TST-007 | COMPLETED 状态下添加用例 | 400 + 错误提示 |
| TC-API-TST-008 | 单次批量添加 > 200 条 | 413 + "单次最多 200 条" |

## 4. 全局搜索接口

| 用例编号 | 场景 | 预期 |
|---|---|---|
| TC-API-SRC-001 | 搜索关键词「登录」 | 返回包含该词的项目/工作项/用户 |
| TC-API-SRC-002 | 空关键词 | 返回空结果 |
| TC-API-SRC-003 | 关键词 > 64 字符 | 422 + "关键词最长 64" |
| TC-API-SRC-004 | MEMBER 搜索（无权限） | 返回空结果（不泄露存在性） |
