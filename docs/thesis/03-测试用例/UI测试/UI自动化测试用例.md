# UI 自动化测试用例

> 工具：Playwright（真实浏览器驱动） ｜ 被测环境：http://localhost:8081
> 用例设计方法：**场景法**（覆盖核心用户旅程）

## 用例清单

### TC-UI-001：登录成功进入工作台

| 项 | 内容 |
|---|---|
| 用例编号 | TC-UI-001 |
| 优先级 | P0 |
| 前置条件 | demo_admin 账号可用 |
| 操作步骤 | 1. 打开登录页<br>2. 输入用户名 demo_admin<br>3. 输入密码 Demo@123456<br>4. 点击登录按钮 |
| 预期结果 | URL 跳转到 /workspace；页面显示「工作台」；侧边栏显示全部菜单 |
