# Phase B 功能遍历清单（复制为 my-checklist.md 使用）

> 勾选规则：✅ 正常 ｜ ⚠️ 有异常（去 bug-log 登记） ｜ ➖ 未测
> 每个模块都按「正常流 → 边界 → 异常流」三遍走。账号策略见指南 §1。

## 0. 登录与会话
- [ ] 正确登录（demo_admin）→ 跳转首页
- [ ] 错误密码提示不泄露账号存在性；连续错 5 次锁定行为
- [ ] 登出后浏览器回退 → 受保护页重新拦截
- [ ] 修改密码 → 旧会话作废 → 新密码可登录、旧密码不可
- [ ] 同一账号第二个浏览器登录 → 第一个会话被顶（单会话）

## 1. 个人中心（/profile）
- [ ] 昵称/邮箱修改并即时生效（顶栏、欢迎语）
- [ ] 邮箱改为他人已占用邮箱 → 明确报错
- [ ] 昵称 50 字边界、邮箱格式校验
- [ ] 我的待办数量与实际指派一致；点击直达对应项目看板

## 2. 组织管理（ADMIN）
- [ ] 新建组织（code 规则：大写字母开头）/ 编辑 / 删除（级联验证）
- [ ] 部门树增删改、层级展示
- [ ] 成员添加/移除/角色变更；组织内 ADMIN 与 MEMBER 边界
- [ ] demo_pm 视角：看不到任何系统管理入口

## 3. 项目管理
- [ ] 新建项目（key 唯一性、大小写规则）/ 编辑 / 归档 / 恢复
- [ ] 归档项目在列表与筛选中的表现
- [ ] 成员管理：添加（须先入组织）、移除 OWNER 被拒
- [ ] 操作列分组与颜色语义符合规范（蓝=导航/编辑，橙=可逆管理，红=删除）

## 4. Issue 生命周期（核心，重点测）
- [ ] 新建（类型/优先级/严重度仅 BUG/经办人须项目成员/编号连续）
- [ ] 编辑：标题描述改、issueNo/报告人不可改
- [ ] 状态流转（列表下拉 + 看板拖拽 + 详情抽屉三种入口）：
      待处理→处理中→已解决→测试中→已关闭；测试中→重新打开→处理中
- [ ] **非法流转被拒**（如 待处理→已关闭；看板拖拽与抽屉按钮都不应出现非法目标）
- [ ] 并发：双浏览器同时流转同一 Issue → 后者得到明确错误而非静默错乱
- [ ] 分派/取消分派；被分派人收到通知红点
- [ ] 列表筛选（关键词/类型/优先级/严重度/状态组合）、分页
- [ ] 状态列下拉显示中文「当前状态」（禁用态）+ 合法目标

## 5. Issue 详情抽屉
- [ ] 看板卡片点击 / 列表编号点击 → 抽屉滑出，信息完整一致
- [ ] 评论：发表（2~3 条）/ 删除他人评论被拒（前端无按钮 + 后端 403）
- [ ] 附件：上传 txt/json、下载内容一致、删除（仅本人或 ADMIN）
- [ ] 超限上传（>10MB）与非白名单类型被拒
- [ ] 流转按钮随状态变化；REOPENED 为橙色警示

## 6. 看板
- [ ] 六列顺序 = 流转顺序；卡片归列正确；列头计数准确
- [ ] 拖拽合法流转成功提示；拖到非法列被拦截并提示
- [ ] 无 issue:transition 权限（demo_pm）卡片不可拖
- [ ] 刷新后状态持久；看板与列表数据一致

## 7. 用例库（重点）
- [ ] 目录树增删改（子目录级联、用例退回未分类不丢失）
- [ ] 新建用例全字段；编号 TC-N 连续
- [ ] 导出 Excel：文件名、列结构、中文枚举、编号列
- [ ] 导入 Excel：导出文件直接回导 → 全部成功；改坏一行标题 → 行级错误提示准确且不影响其他行
- [ ] 导入自动创建不存在的目录
- [ ] 非成员访问用例库 → 「仅项目成员可操作」

## 8. 测试计划与报告
- [ ] 新建计划（自动 NOT_STARTED）→ 添加用例（从库挑选、去重）
- [ ] 执行打结果：通过/失败（失败须可关联 Bug）/阻塞（原因必填）
- [ ] NOT_STARTED 不可执行、COMPLETED 不可再执行/加用例（后端拒绝）
- [ ] 报告页：通过率计算（按已执行）正确；<80% 红字；环图与明细一致
- [ ] 报告页关联缺陷标题正确、执行人统计与明细一致

## 9. Dashboard
- [ ] 统计卡与真实数据一致（对照各页总数）
- [ ] 环图中文图例、趋势图日期连续
- [ ] demo_pm（无 dashboard:view）只见快捷入口 + 待办，不报错

## 10. 在线会话（ADMIN）
- [ ] 列表含全部在线用户、剩余有效期合理、自己标记当前登录
- [ ] 踢下线确认框 → 目标用户下一请求 401 回登录页
- [ ] 自己行「踢下线」禁用；直接 API 自踢 → 400
- [ ] demo_pm 无此菜单；直访 /system/sessions → 拒绝

## 11. 通知与审计
- [ ] 分派/流转/评论触发通知；已读/全部已读；登出后通知不残留到他人
- [ ] 审计日志记录登录/登出/增删改；不包含密码等敏感字段

## 12. 通用/横切
- [ ] 全站无英文枚举裸奔（类型/状态/优先级全部中文）
- [ ] F12 控制台无报错；接口响应无堆栈/SQL 泄漏
- [ ] XSS 冒烟：Issue 标题/评论输入 `<script>alert(1)</script>` → 纯文本渲染不执行
- [ ] 直接调用接口伪造 reporter / 越权 id → 403/404
